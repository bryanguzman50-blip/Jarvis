# Knowledge Base

This folder is Jarvis's long-term memory about Bryan and his business. Jarvis reads these files before answering questions about the business or drafting anything in Bryan's voice (toolkit item #9: "answer customers in your voice").

| File | What goes in it |
|---|---|
| `profile.md` | Who Bryan is — background, goals, preferences |
| `business.md` | The wholesaling operation — market, pipeline stages, deal criteria |
| `voice.md` | How Bryan writes and talks, so drafts sound like him |
| `faq.md` | Standard answers to questions sellers and buyers ask |

**How to grow it:** just tell Jarvis things — "add to my knowledge base: my buy box is 3/2s under $150k in Cook County" — and he'll file them in the right document. The more that's in here, the less generic Jarvis sounds.
